Publish a dock

A curator's sheet becomes lists/<dock>.json. Nothing leaves this page except the file you download.

Dock

How a sheet is read. The first sheet whose header row has Q1 and A1. Columns are found by name, in any order: LVL (or LEVEL, SEG) · ENT · CAT · SUB · TAG (or TAGS) · Q1 A1 … Q10 A10. A row is published when it has Q1 and A1; the rest is optional. An empty ENT takes A1.

IDs. Stamped here from the row's place among the published rows: the first is 0001. Publish = freeze: when this site already has a lists/<dock>.json, every row in it must still be at its place with the same word and class. New rows go after the last published one. If something moved, the download stops and says where.

Then. Put the file at lists/<dock>.json in the repository and commit. If the dock is new, add its name to the DOCK_NAMES line near the top of the script in lens.html.
