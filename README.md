# WordDock

**Efficient learning and collaboration.**

WordDock is a free, lightweight, browser-based (vocabulary) trainer built around weakest-first repetition and deep drilling.
No account, no email, no password.
Your progress lives in your browser; an optional sync key makes a cloud copy so your devices share it.

Live app: **[worddock.app](https://worddock.app)**

## How it works

- **Static-first.** The entire app is a single HTML file that runs in your browser, offline included.
- **Weakest-first repetition.** Every card carries a score; the ten weakest come back first, until they stick.
- **Progress is yours.** Scores stay in your browser, per list. Turn on sync and a random 8-character key carries them to your other devices - the server stores a key and some numbers, never who you are.
- **Collective lists, private progress.** Decks are exchanged as files between people; scores never travel in a file.
